# VINTAGE 재고관리

**👉 접속 주소: https://vintage.jjurang.workers.dev/**
(휴대폰·PC에서 열고 "앱 설치" / "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다)

빈티지샵 여러 매장(1·2·3호점…)이 **상품 재고와 판매 상태를 실시간으로 공유**하는 내부 프로그램입니다.

- 실장이 **사진 + 상품코드**로 상품을 등록합니다.
- 판매되면 **[판매 처리]** 를 누릅니다. 다른 매장 화면에도 즉시 "판매완료"로 바뀌고 알림이 뜹니다.
- 상품코드로 검색하면 **어느 매장에 재고가 있는지 / 이미 팔렸는지** 바로 확인할 수 있습니다.
- 계정은 **관리자가 아이디를 만들어서** 실장에게 줍니다. 회원가입은 없습니다.
- **QR · 바코드 라벨 출력**: 상품 화면에서 [라벨 출력]을 누르면 QR코드와 바코드가 함께 들어간 라벨이 인쇄됩니다. 라벨프린터 50×30, 40×30, 60×40mm와 A4 21칸 스티커를 지원합니다.
- **상품 판매 (계산대 화면)**: 바코드 스캐너나 휴대폰 카메라로 찍으면 **장바구니**에 담깁니다. 가격을 고치거나 추가 할인을 넣은 뒤 **[현금] [카드] [이체]**로 한 번에 결제합니다. 현금은 받은 금액을 넣으면 거스름돈이 계산됩니다.
- **영수증**: 결제 후 출력(80mm/58mm 영수증 프린터)하거나 자동으로 출력할 수 있습니다. 오늘 판매나 정산 목록에서 다시 출력하거나 취소할 수도 있습니다. 매장별 상호·사업자번호·주소·하단 문구는 [관리자 → 매장 정보]에서 설정합니다.
- **시재 관리**: 영업 시작 때 시작 시재를 입력하고, 중간에 입금·출금(잔돈 보충, 지출 등)을 기록합니다. 마감 때는 권종별로 현금을 세서 입력하면 **있어야 할 현금과의 과부족**이 기록됩니다.
- **정산**: 기간별·매장별 총 매출, 결제 건수, 현금/카드/이체·할인 합계, 판매자별 합계, 시재 기록, 영수증 목록을 보여주고 엑셀(CSV)로 받을 수 있습니다.
- **회원 · 포인트 · 쿠폰**:
  - 계산대에서 회원을 전화번호로 찾거나 바로 가입시킬 수 있습니다. 결제 금액의 n%가 적립됩니다(기본 1%).
  - 포인트는 1P = 1원으로 쓰고, 쿠폰은 코드를 입력해 적용합니다. 정액·정률, 최소 결제금액, 기간, 사용 횟수를 설정할 수 있습니다.
  - 영수증을 취소하면 적립 포인트는 회수되고, 사용한 포인트와 쿠폰은 되돌려집니다.
  - [회원] 메뉴에서 구매 내역과 포인트 내역을 볼 수 있고, [관리자]에서 포인트 설정과 쿠폰을 관리합니다.
  - **QR 회원가입**: [관리자 → 매장 → 📱 회원가입 QR]에서 안내문을 인쇄해 붙여두면, 손님이 휴대폰으로 찍어 직접 가입합니다. 개인정보 동의(필수)와 문자 수신 동의(선택)를 받습니다. 가입 축하 포인트도 설정할 수 있고, 계산대의 [회원 찾기] 창에서도 QR을 바로 띄울 수 있습니다. 안내문은 **[🎨 안내문 꾸미기]**에서 테마 4종(빈티지 크림·블랙·미니멀·세이지), 제목·혜택·하단 문구, 용지(A4/A5/A6)를 바꿔 인쇄하거나 PDF로 저장할 수 있습니다. QR은 [QR 새로 만들기]를 누르기 전까지 계속 유효합니다.
  - 적립률은 0.5%, 2.5%처럼 소수점까지 설정할 수 있습니다.
  - **문자 수신 동의 회원 관리**: [회원 → 📩 문자 수신 동의만]에서 동의한 회원만 모아보고, 번호 복사나 엑셀(CSV)로 받을 수 있습니다. 동의일이 기록되고, 수신 거부 요청 시 회원 정보에서 해제합니다.
  - **쿠폰 보내기(발급)**: [관리자 → 쿠폰 → 회원에게 보내기]를 누르면 문자 수신 동의 회원이나 전체 회원 계정에 쿠폰이 들어갑니다. 계산대에서 회원을 선택하면 **보유 쿠폰**을 눌러 바로 적용합니다. 발급 후에는 안내 문자 문구와 받는 번호(동의 회원만)를 복사할 수 있습니다.
  - **회원 전용 쿠폰**: 켜두면 발급받은 회원만 쓸 수 있어서, 코드가 퍼져도 남용되지 않습니다.
- **계정 삭제**: 관리자와 총관리자가 실장·캐셔 계정을 삭제할 수 있습니다. 판매 기록이 있는 계정은 기록에 이름만 남기고 로그인은 영구 삭제되며, 같은 아이디를 다시 만들 수 있습니다.
- **캐셔 계정**: [상품 판매] · [정산] · [내정보]만 보이는 계정입니다. 상품 등록이나 수정은 할 수 없고, 본인이 오늘 판매한 건만 취소할 수 있습니다.
- 접속 방법은 두 가지입니다. **웹사이트(도메인)** 로 바로 열거나, 휴대폰/PC에 **앱처럼 설치(PWA)** 할 수 있습니다.

## 구성

| 역할 | 사용 기술 |
|---|---|
| DB · 로그인 · 사진 저장 · 실시간 동기화 | [Supabase](https://supabase.com) |
| 화면 (웹앱 / 설치형 앱) | `public/` 폴더의 정적 파일 (빌드 과정 없음) |
| 직원 계정 생성 | Supabase Edge Function `admin-users` |

```
public/                  ← 호스팅(도메인)에 올리는 폴더
  index.html, app.js, style.css
  config.js              ← Supabase 주소/키 입력
  manifest.webmanifest, sw.js, icons/   ← 앱 설치(PWA)용
  vendor/                ← supabase-js 라이브러리
supabase/
  schema.sql             ← 테이블·권한·판매처리 함수·사진저장소 (SQL Editor에서 실행)
  bootstrap-admin.sql    ← (선택) 대시보드에서 직접 관리자 연결
  functions/admin-users/ ← 관리자 전용 계정 생성/수정 함수
```

### 이용기간 (월 단위 사용 승인)
- 총관리자가 **[이용관리]** 메뉴에서 입금 확인 후 **[+1개월 연장]** (메모: "11월분 입금 확인" 등) → 이력에 남음
- 만료 7일 전부터 관리자 화면에 "이용기간 D-n" 안내
- 만료 후 **유예기간(기본 3일)** 동안은 경고만 표시, 그 뒤엔 총관리자 외 **모든 직원 사용 중지** (DB 단에서 차단)
- 데이터는 지워지지 않으며, 연장하는 즉시 다시 사용 가능
- 총관리자는 앱에서 만들 수 없고 [`supabase/bootstrap-admin.sql`](supabase/bootstrap-admin.sql) 의 SQL 로만 지정

- 두 매장에서 같은 상품을 동시에 판매 처리해도 **한 번만 성공**합니다. DB 행 잠금으로 막습니다.
- 모든 등록/판매/취소/이동은 **이력**으로 남습니다.
- 계정을 "정지"하면 즉시 로그인과 데이터 접근이 차단됩니다.

## 설치 방법

### 1. Supabase 프로젝트 만들기
1. https://supabase.com 에서 새 프로젝트를 만듭니다. Region은 **Northeast Asia (Seoul)** 을 고르세요.
2. **SQL Editor** 에 [`supabase/schema.sql`](supabase/schema.sql) 전체를 붙여넣고 **Run** 합니다.
   - 기본 매장 `1호점`, `2호점`, `3호점`과 사진 저장소 `photos`가 만들어집니다.

### 2. 로그인 설정
**Authentication → Sign In / Providers → Email** 에서 **Confirm email → 끄기**
> "Allow new users to sign up" 은 **최초 관리자를 만들 때까지 켜둡니다** (3번 끝나고 끄기).

### 3. 최초 관리자 만들기 (앱에서)
앱(5·6번 이후 배포된 주소, 또는 로컬 미리보기)을 처음 열면 **"총관리자(개발자) 만들기"** 화면이 나옵니다.
아이디/이름/비밀번호를 넣고 누르면 바로 **총관리자**로 로그인됩니다. 이 화면은 한 번만 나옵니다.
그다음 [관리자] 메뉴에서 매장 사장님용 **관리자** 계정과 실장 계정을 만드세요.

그다음 **Authentication → Sign In / Providers → "Allow new users to sign up" 끄기** 를 꼭 해주세요.
> 로그인 아이디는 내부적으로 `아이디@vintage.local` 이메일로 저장됩니다. 실제 메일은 발송되지 않습니다.
> (앱 없이 대시보드로 직접 만드는 방법은 [`supabase/bootstrap-admin.sql`](supabase/bootstrap-admin.sql) 참고)

### 4. 계정 생성 함수(Edge Function) 배포
관리자 화면에서 실장 계정을 만들 때 쓰는 함수입니다.

**방법 A: 대시보드**
Edge Functions → **Deploy a new function** → **Via Editor**. 이름은 `admin-users`로 하고, [`supabase/functions/admin-users/index.ts`](supabase/functions/admin-users/index.ts) 내용을 붙여넣은 뒤 Deploy 합니다.

**방법 B: CLI**
```bash
npx supabase login
npx supabase functions deploy admin-users --project-ref <프로젝트ID>
```

### 5. 앱에 Supabase 연결
Project Settings → API (또는 API Keys) 에서 **Project URL** 과 **anon / publishable key** 를 복사합니다. 그 값을 [`public/config.js`](public/config.js)에 넣습니다.
> ⚠️ `service_role` / `secret` 키는 절대 넣지 마세요.

### 6. 도메인으로 배포 (무료 호스팅)
Vercel, Netlify, Cloudflare Pages 중 하나에서 이 GitHub 저장소를 연결합니다.
- Build command: **없음**
- Output / Publish directory: **`public`**

현재 배포 주소는 **https://vintage.jjurang.workers.dev/** (Cloudflare Workers) 입니다.
배포가 끝나면 호스팅 설정의 **Custom Domain** 에서 보유한 도메인을 연결합니다. 예: `stock.내도메인.com`.
GitHub에 push할 때마다 자동으로 다시 배포됩니다.

### 7. 앱으로 설치 (다운로드해서 쓰기)
배포된 주소로 접속한 뒤:
- **안드로이드(크롬)**: ⋮ → **앱 설치**
- **아이폰(사파리)**: 공유 □↑ → **홈 화면에 추가**
- **PC(크롬/엣지)**: 주소창 오른쪽 설치 아이콘 ⊕

로그인 후 **내정보** 화면에도 같은 안내가 있습니다.

### 로컬에서 미리보기
```bash
npx serve public
```

## 사진 용량 / 비용 참고
- 사진은 업로드 전에 휴대폰에서 자동으로 압축됩니다. **원본 ≈ 150~250KB (1280px)**, **썸네일 ≈ 20~40KB (480px)** 입니다.
- 목록 화면은 썸네일만 불러오므로 데이터 사용량(egress)이 적습니다.
- 상품 1개당 대략 **0.25MB** 를 씁니다.
  - Supabase 무료 플랜(Storage 1GB 기준): 약 **4,000개**
  - Pro 플랜(Storage 100GB 포함): 약 **40만 개**
- 상품을 수정하거나 삭제하면 예전 사진도 자동으로 지워집니다.
- 무료 플랜은 일정 기간 사용이 없으면 프로젝트가 일시정지될 수 있습니다. 매장에서 매일 쓴다면 문제없지만, 운영용이라면 Pro 플랜을 권장합니다.
- 요금과 한도는 바뀔 수 있으니 https://supabase.com/pricing 에서 확인하세요.

## 준비만 되어 있는 것 (DB 구조만, 화면은 나중에)
- **교환 · 부분환불**: `refund_sale_items` 함수와 영수증의 환불 필드. 교환은 "부분환불 + 새 결제"로 처리합니다.
- **토스플레이스 연동**: 매장별 가맹점 ID, 영수증의 외부 결제번호(중복 방지 포함), `checkout(..., p_external)`. 자세한 내용은 [`docs/toss-integration.md`](docs/toss-integration.md)에 있습니다.

## 앞으로 확장할 수 있는 것
- **재고조사 모드**: 매장 상품을 쭉 스캔한 뒤 "DB엔 있는데 매장에 없는 상품" 목록 자동 생성
- 매출 통계(매장별/기간별), 엑셀 내보내기
